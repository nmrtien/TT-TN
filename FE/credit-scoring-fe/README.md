# Credit Scoring FE

FE thuần HTML/CSS/JavaScript cho hệ thống quản lý hồ sơ chấm điểm tín dụng.

## Chạy nhanh
Mở `index.html` bằng trình duyệt hoặc dùng Live Server.

## Cấu trúc
- `pages/`: các màn hình
- `css/`: style tách riêng
- `js/`: logic/API tách riêng
- `assets/`: hình ảnh/icon

## Kết nối Spring Boot
Mở `js/api.js`:
- đổi `API_BASE_URL`
- đổi `MOCK_MODE = false`
- bổ sung endpoint thật trong các module JS.

Dữ liệu hiện tại là mock để có thể chạy UI ngay.
